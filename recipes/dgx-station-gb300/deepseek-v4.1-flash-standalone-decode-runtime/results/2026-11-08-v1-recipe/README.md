# results/2026-11-08-v1-recipe

First results bundle for the standalone decode runtime recipe. Everything under `raw/` is a copy of a file from
`jmeadlock/gb300-dsv41-decode` at `ed6582e` (`docs/` unless noted), byte-identical except one scrub:
`raw/CUTOVER.md` had one private LAN address (Spark 1) replaced with `LAN-HOST`. No receipt was edited, trimmed or
re-derived. Nothing here was measured by the recipe writer; no box access, ssh, docker or network was used.
`SHA256SUMS` covers every file except this README and itself. `throughput.csv` was generated by a one-shot script from the
receipts (columns: metric, value, unit, source file); rows marked "derived" are arithmetic on a named field.
